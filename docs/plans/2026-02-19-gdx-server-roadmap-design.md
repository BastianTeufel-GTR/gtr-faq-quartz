## Page Structure

1. **Frontmatter** — title, tags (roadmap, development)
2. **Product summary** — 2 sentences: what GDX Server is, REST API for ProfDia environments
3. **`[!quote]` Community callout** — license holders can participate, Pro/Enterprise can suggest & prioritize, planned Discord server
4. **`[!success]+` Completed features** (collapsed by default) — grouped by tier (All / Pro+Enterprise / Enterprise)
5. **`[!info]` Basic planned features** — priority labels, `==highlights==` on Next up items
6. **`[!tip]` Pro / Enterprise planned features** — priority labels
7. **`[!example]` Enterprise planned features** — priority labels

## Priority Labels
- `Next up` — actively approaching development
- `Planned` — confirmed, not yet scheduled
- `Under consideration` — likely but not committed

When a feature enters active development, the label gets replaced with a quarterly target (e.g., `Q3 2026`).
