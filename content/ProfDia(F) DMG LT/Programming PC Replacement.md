# ProfDia LT20 / LT50 PT Prerequisites

This page covers the migration of an existing ProfDia(F) installation to a new PC. Fulfill the following topics before the actual installation.

## PC Requirements

> [!info] PC Requirements
> Hardware, operating system, PC preparation and network setup apply to all ProfDia versions.
> See [[PC Requirements]].

## Migration Preparations

- A local method for transferring the data to the new PC must be available (USB drive, network share, ...).
- If the database is located on a network drive, the new PC needs the same privileges and network drive mappings as the old PC. This includes the same drive letters.
- If the migration is done with GTR remote support, RustDesk must show **Ready** on the **old PC** and on the **new PC**. See [[rustdesk-remote-support|RustDesk Remote Support]].

## Finalization

After a successful migration to the new PC, create a full backup or image of the newly installed PC.
